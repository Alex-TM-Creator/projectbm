# **App Name**: Conecta Empresa

## Core Features:

- Login Unificado: Acesso ao sistema via e-mail ou 'nickname.nomedaempresa'.
- Cadastro de Empresas: Aba para cadastrar nomes de empresas, essencial para o formato de login 'nickname.nomedaempresa'.
- Gerenciamento de Usuários: Permite ao administrador cadastrar novos usuários, definir senhas temporárias e atribuir permissões de administrador.
- Definição de Filiais: Permite ao administrador cadastrar filiais, para fins de gestão de usuários.
- Definição de Funções: Permite ao administrador cadastrar funções de usuário, para fins de gestão de usuários.
- Painel de Controle: Exibe estatísticas sobre o número de usuários cadastrados no sistema.
- Personalização da Interface: Aba de configurações para habilitar/desabilitar o modo escuro.

## Style Guidelines:

- Primary color: Deep violet (#673AB7) to evoke innovation and sophistication.
- Background color: Very light violet (#F3E5F5).
- Accent color: Electric blue (#3F51B5) for interactive elements.
- Headline font: 'Poppins' sans-serif font for a modern and fashionable look.
- Body font: 'PT Sans', sans-serif, complementing the header for readability and clarity.
- Minimalist icons with a focus on clarity and intuitive understanding.
- Subtle transitions and animations to enhance user experience.
